# Демонстрация наследования в Python

Небольшая программа показывает работу базового и производного классов
на примере банковских счетов.

## Что демонстрирует программа

- создание объекта базового класса `BankAccount`;
- создание объекта производного класса `SavingsAccount`;
- вызов методов базового класса;
- использование унаследованного метода `deposit`;
- переопределение методов `show_info` и `withdraw`;
- вызов метода базового класса из производного через `super()`.

## Требования

- Python 3.8 или новее
